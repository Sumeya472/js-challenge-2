# JavaScript Challenge 2 

A collection of JavaScript practice challenges focused on arrays, objects, functions, array methods, destructuring, and modern JavaScript syntax.

This repository contains five practical exercises designed to strengthen problem-solving skills and build a solid foundation for learning TypeScript and React.

## Challenges

| No. | Challenge | Description |
|---|---|---|
| 11 | Employee Salary Summary | Categorize employees by salary and calculate salary statistics. |
| 12 | Quiz Score Analyzer | Calculate student grades, identify top performers, and count passed students. |
| 13 | Recipe Ingredient List | Format ingredient lists and analyze recipe ingredients. |
| 14 | Gym Class Board | Display gym schedules, available seats, and booking statistics. |

##  Concepts Practiced

- **Variables:** `const` and `let`
- **Functions:** Regular functions and arrow functions
- **Template Literals:** Dynamic string formatting
- **Ternary Operator:** Conditional expressions
- **Object Destructuring:** Extracting object properties
- **Array Methods:**
  - `.map()`
  - `.filter()`
  - `.reduce()`
  - `.find()`
  - `.some()`
  - `.every()`
- **String Methods:** `.split()`, `.join()`, `.includes()`, `.toUpperCase()`
- **Object Methods:** `Object.keys()`, `Object.values()`, `Object.entries()`
- **Spread Syntax:** `...`
- **Math Methods:** `Math.round()`, `Math.max()`, `Math.min()`
- **Modern JavaScript:** Optional chaining (`?.`) and nullish coalescing (`??`)
- **Loops:** `for...of`

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Sumeya472/js-challenge-2.git
   ```

2. Navigate into the project:

   ```bash
   cd js-challenge-2
   ```

3. Run a challenge using Node.js:

   ```bash
   node filename.js
   ```

   Replace `filename.js` with the name of the JavaScript file you want to execute.
